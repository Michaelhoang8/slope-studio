Numerics & plot bounds
Syntax and numerical methods

Use x, y, numbers, + − * /, parentheses, integer powers ^0 through ^8, and sin, cos, exp, log, sqrt. Unary minus follows conventional power precedence: -x^2 means -(x^2). No code evaluation or arbitrary functions.

Gradient descent uses the raw gradient. Momentum uses v ← 0.9v + g. Adam uses β₁ = 0.9, β₂ = 0.999, bias correction, and ε = 10⁻⁸. Optional norm clipping applies before optimizer state updates; recorded gradients remain unclipped. There is no stochastic sampling, line search, or constraint projection.

The surface is a 64 × 64 grid of cell-center samples with a log-compressed color range. Undefined samples are gray. Runs stop at the step budget, gradient tolerance, invalid arithmetic, or coordinates outside ±10⁶. sqrt at zero is rejected for gradient evaluation because its local derivative is not finite.

Analysis

Loss by iteration

Scale: sign(f) × log(1 + |f|). Shared learning rate across methods.

Selected point

Gradient tolerance checks stationarity, not whether the point is a minimum.

Numerical gradient cross-check

Central differences use h = 10⁻⁵ × max(1, |coordinate|). Agreement is diagnostic; cancellation and invalid neighboring points can limit it.

Derivative tape

Forward values flow through the tape; the output adjoint starts at one. Each reverse edge adds upstream adjoint × local derivative to its input. Shared x/y nodes accumulate every contribution.

Plot details

Arrow keys move the starting point by 1% of the plot span; Enter runs. Trajectories outside the bounds are clipped.
